Model & Usage Disclaimer

How the Model Works

This system uses pose landmarks extracted via MediaPipe. Hand-crafted biomechanical features are passed into a classical machine learning classifier to predict swing outcome.

Explainability

Predictions are based on interpretable features such as elbow angle, arm extension, and torso rotation — not raw pixels.

Intended Usage

Educational demos, ML portfolios, human-motion research, and AI explainability showcases.

This is an experimental AI system built strictly for educational and demonstration purposes. Predictions are probabilistic and should not be used for professional coaching, scouting, medical evaluation, betting, or performance assessment. Not trained on professional datasets. Sensitive to camera angle, lighting, and pose visibility.
